# Day 1 마무리 — 데이터 확인과 개발셋 A/B 비교

- 날짜: 2026-10-20
- 브랜치: `feat/day1-evaluation-prep`
- Day 2에서 추가했던 ADR 0003/0005와 ignore 변경은 먼저 되돌렸다. Agent·SSE 구현은 시작하지 않았다. 현재 변경은 Day 1 평가·데이터 준비와 해당 메타데이터 표시다.

## 완료한 준비

- 세 영상 제목·NCT WISH 채널을 YouTube 공식 oEmbed로 확인해 로컬 manifest에 반영했다.
- 사용자에게 Wave 도구 추출 출처를 확인하고 공식 안내·약관을 읽어 [출처 기록](day1-data-provenance.md)을 작성했다. 제삼자 자막 공개 재배포 권한을 확인했다고 주장하지 않는다.
- 사용자가 영상별 3점, 총 9점의 링크 내용 일치를 확인했다. [시각 확인표](day1-timing-checklist.md)에 확인 주체와 표본 범위를 기록했다.
- 실제 cue 기반 개발 질문 5개와 gold 초안 24개를 eval/private에 보관했다. source cue ID·허용 구간이 실제 원문과 연결되는지 코드로 검사했다.
- gold 초안은 장면 질문 14개·화자 미확인 4개·영상 판독 범위 밖 2개·부재 검토 후보 4개다. 마지막 4개는 관련 영문 검색어 미등장만 확인했으며 의미적 부재는 미확정이다.
- gold는 검색·튜닝에 사용하지 않았다. 내용 라벨은 assistant source cue 검토 초안이며 사람 검토·확정은 Day 2까지 필요하다.

## 개발 질문 5개 고정 A/B 비교

모든 조건에서 같은 3편·3,750 cue·동일 정답을 사용했다. 클릭 링크의 시작 시각 한 점과 정답 영상/구간 ±10초를 비교했다. 각 문항은 조건별 1회 측정했다.

| 검색어 조건 | 방식 | Scene Success@1 | Hit@3 | 평균 검색·원문 검증 시간 |
|---|---|---|---|---|
| 한국어 원문 | A: BM25Plus | 0/5 | 0/5 | 0.0017초 |
| 한국어 원문 | B: Hybrid | 3/5 | 4/5 | 1.2508초 |
| 고정 모델 영어 재구성 | A: BM25Plus | 2/5 | 2/5 | 0.0051초 |
| 고정 모델 영어 재구성 | B: Hybrid | 2/5 | 3/5 | 0.4335초 |

MCP/모델 준비 시간은 6.205초로 별도 측정했다. 영어 재구성 생성은 9.82초였으며 위 검색 시간에 포함하지 않는다.

한국어 원문의 BM25는 영어 corpus와 토큰 일치가 없어 0건이었다. 이 차이를 Hybrid의 의미 이해나 Agent 효과만으로 설명하지 않는다. 영어 조건도 A/B에 같은 저장 검색어를 주었으며, 결과를 보고 검색어를 고치지 않았다.

## 실패와 해석

- 한국어 Hybrid에서 마니또·버터 감자·두바이 쿠키는 1위 성공, 료칸 질문은 2위, 감/kaki 질문은 Top 3 실패였다.
- qwen3:8b의 영어 재구성이 료칸 질문을 RYO/Secret Santa로 바꾸고 감·감자를 grape/grapes로 잘못 변환했다. 오류 출력도 원본 그대로 동결했다. 영어 변환이 항상 검색을 개선하지 않았다.
- 위 지표는 개발 질문 관측이다. 금번에는 검색 파라미터·제품 프롬프트를 조정하지 않았으며 최종 held-out 성능이나 Agent C 결과로 쓰지 않는다.
- 실행 순서는 한국어 A→B→영어 A→B이며 cue 임베딩 캐시가 뒤 조건에 유리할 수 있다. 평균 시간 차이를 통계적으로 비교하지 않는다. p95·기권 정확도·재검색 효과는 미측정이다.

## 재현과 검증

실행 명령과 공개 합성 예시는 [eval 안내](../../eval/README.md)를 따른다. corpus 원본 해시·개발셋 해시·고정 검색어 해시·문항별 결과·도구 호출 수는 로컬 결과 JSON에 남겼다. 자막 전문과 실제 gold는 공개하지 않는다.
