## 1. 이중 첫 검색 (OpenAI, gold 20문항, 끔 vs 켬)
명령: `WISH_LLM_BACKEND=openai WISH_DUAL_QUERY={0|1} python -m eval.run_eval --dataset eval/private/gold.jsonl --systems A,B,C --control --max-llm-calls 150` (각 120건, 오류 0건).

C 결과는 끔/켬이 같다: Success@1 16/18, Hit@3 16/18, 화자 3/4, 거부 2/2, 확신 오답 1, 근거 없는 화자 단정 0, LLM 호출 42. 검색 호출은 80 → 98. 평균 지연 2.56 → 2.38초(우연 범위). 놓친 두 문항이 두 실행에서 같다. **정확도 이득은 확인되지 않았고 기본값은 off 유지.**
