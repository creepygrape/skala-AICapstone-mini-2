## 우선순위 내릴 순서 (P0 보존 원칙)

1. OCR, ASR, 화자 식별/수동 태깅, 자동 YouTube 크롤링, 고급 디자인은 착수 금지(P2).
2. 긴 후속 질문 저장, 다중 영상 비교, 관리자 데이터 업로드 UI는 후순위(P1).
3. 모델별 비용 티어링·검색 병렬화·MCP Resource/Prompt 확대는 핵심 작동 후(P1).
4. 서버 동작·SSE·근거 검증·ADR·평가는 축소하지 않는다. P0 일정 자체가 불가능한 경우 실제 리스크와 축소안을 사용자에게 제시한다.
