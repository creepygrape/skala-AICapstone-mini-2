# ADR-0006 — 문맥 기반 윈도우 청킹과 원본 cue 역참조

- 상태: Proposed
- 날짜: 2026-10-20
- 관련 요구사항: FR-01, FR-02, FR-09

## 배경
원본 SRT는 수초 이하의 작은 구간으로 분리된 대화가 많다. '마니또를 뽑다가 자기 자신을 뽑은 장면'처럼 상황은 여러 cue에 걸쳐 나타날 수 있으며 개별 cue 검색은 문맥을 놓칠 수 있다.

## 결정
기본 가설로 영상별 20초 윈도우(10초 중첩)를 사용한다. 인덱싱 청크는 관련 cue IDs를 보유하며 영상 경계를 절대 넘지 않는다. 최종 결과는 검색 청크 점수 대신 원본 cue의 인용과 start/end를 인용 출처로 사용한다. 근거가 특정 cue에 있다면 해당 cue 시점에 링크한다.

## 대안과 트레이드오프
- cue 1개 단위: 가장 정확한 시점이지만 앞뒤 의미가 끊김.
- 긴 문단 단위: 문맥이 많으나 시점 정밀도와 검색 특이성이 낮아질 수 있음.
- 중첩 시간 윈도우: 문맥·시점 균형, 중복 검색 결과 제거 필요.

## 영향 및 검증
20초/10초는 아직 측정되지 않은 기본값이다. 테스트 질문에서 10초/20초/30초 단위를 비교하고 중복 청크 억제, 경계 맞춤, 정확한 시점 링크를 검사한다.

## 재검토 조건
정답 장면의 앞뒤 문맥 분리 또는 과도한 유사 청크 중복으로 Scene Success@1이 떨어지는 경우.

## Day 1 구현 기준 (2026-10-20)
20초 창/10초 이동을 기본 가설로 유지한다. 시작 시각 기반 배치로 긴 cue의 반복 삽입을 막고 20초보다 긴 cue는 단독 항목으로 보존한다. cue 1220 길이는 75.091초다. 중복 장면은 결과 순위를 계산하기 전에 통합한다.

## PR #1 리뷰 반영 — 접두어와 구조 행

반복된 앞 cue는 검색용 텍스트에서만 줄인다. 글자 단위 startswith만으로 자르면 Go/Good, I/It's 등이 손상되므로 완전 반복 또는 뒤에 공백이 오는 경계에서만 제거한다. 구두점만 있는 경계는 축약어와 충돌할 수 있어 보수적으로 유지한다. 원문 cue는 변경하지 않는다.

SRT의 연속 빈 구분 행과 cue ID·시간 행 양끝 공백은 파싱 시 허용하되 자막 본문은 strip하지 않는다. 회귀 테스트로 구조 변형, 본문 공백 보존, 부분 단어·축약어, 실제 반복 접두어를 검사한다. 청크 텍스트가 달라지면 기존 인덱스 해시가 바뀌어 재생성된다.

## 갱신: 청크 길이 비교용 설정 (2026-10-22)

20초/10초가 측정되지 않은 가정이라는 점을 확인하기 위해 `WISH_CHUNK_WINDOW`, `WISH_CHUNK_STRIDE`(기본 20/10, 0 < 이동 ≤ 창 ≤ 120)를 추가하고 평가 결과에 사용한 값을 기록한다(`eval/chunk_sweep.sh`, `eval/README.md`). 기본값과 동작은 그대로다. 비교는 gold 승인 파일이 있는 PC에서 실행해야 한다.

## 결과: 청크 길이 비교 (2026-10-22, 실측)

같은 gold 20문항(장면 18), A/B만 실행(LLM 없음), 한국어 원문 조건, 설정당 질문 1회. 설정마다 dense 인덱스를 새로 만들었다(`eval/chunk_sweep.sh`, 결과는 Git 제외 `eval/private/chunk-<창>-<이동>.json`).

| 창/이동 | 청크 수 | B 1위 적중 (18) | B 상위 3개 (18) | A 1위 | B 평균 지연(초) |
|---|---|---|---|---|---|
| 10/5 | 1,712 | 11 | 13 | 0 | 0.19 |
| **20/10 (기본)** | 869 | 11 | 13 | 0 | 0.30 |
| 30/15 | 580 | 9 | 11 | 0 | 0.41 |
| 40/20 | 439 | 5 | 8 | 0 | 0.43 |

- **결정: 기본값 20/10 유지.** 10/5와 같은 점수에서 청크 수는 절반이고, 30 이상에서 적중이 떨어졌다.
- 한계: 18문항·설정당 1회라 1~2문항 차이는 노이즈일 수 있다. 영어 검색어 조건(gold.rewrites.json 없음)과 Agent(C)는 측정하지 않았다. 지연은 실행 순서·캐시 영향이 있어 청크 길이 효과로 단정하지 않는다. 원인(긴 청크에서 여러 장면 혼합, 선택 cue의 시각 이탈)은 이 실험으로 가르지 못했다.
- 재검토 조건: 더 짧은 창(5/2.5), 영어 조건, Agent 포함 측정에서 20/10보다 뚜렷하게 좋은 설정이 나올 때.
