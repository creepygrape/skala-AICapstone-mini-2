# ADR-0002 — 장면 기억 검색은 BM25 + 다국어 Dense의 Hybrid로 구축한다

- 상태: Proposed
- 날짜: 2026-10-20
- 관련 요구사항: FR-03, FR-04, FR-05, FR-07, FR-16

## 배경
사용자는 정확한 대사가 아닌 상황만 기억한다. 원본 추출 스크립트가 영어일 수 있지만 사용자 질문은 한국어일 수 있다. 이 언어 차이는 **사용자 불편함 자체가 아니라** 검색 파이프라인이 처리할 기술적 제약이다.

## 결정
BM25 기반 정확 용어 검색과 다국어 의미 임베딩 검색을 함께 사용한다. 단순한 RRF로 순위를 융합하는 방안을 우선 검토한다. 검색 인덱스는 영상별 cue 식별자와 타임스탬프를 보존한다. 한국어 쿼리→영어 검색어 재구성은 기본 인덱스/임베딩 성능을 측정한 후 필요 시 사용한다.

## 대안과 트레이드오프
- BM25 단독: 가볍고 빠르나 상황의 의역·다국어 표현에 취약할 수 있음.
- Dense 단독: 의역에 강할 수 있으나 고유명사·세부 인용의 정확한 매칭이 약할 수 있음.
- Hybrid: 추가 의존성·인덱스 비용 및 튜닝 필요, 대신 보완적 신호 사용 가능.

## 영향 및 검증
Baseline A=BM25, B=Hybrid, C=Hybrid+Agent를 같은 corpus/평가셋에서 비교한다. 소규모 SRT 3편에서 Hybrid 성능이 항상 더 높다고 가정하지 않는다.

## 재검토 조건
한국어 질문에 대한 다국어 임베딩 성능/latency가 실측에서 나쁘거나 핵심 질문에서 BM25 단독이 더 나은 경우.
