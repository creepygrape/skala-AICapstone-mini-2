# docs/exec — 제출물과 생성 스크립트 (G078 문희주)

- `G078_문희주_최종보고서_초안.docx`, `G078_문희주_발표.pptx`, `preview_*.pdf`: 제출 초안과 미리보기
- `shots/`, `diagrams/`, `langsmith/`: 보고서·PPT에 들어간 캡처와 도식
- `scripts/`: 보고서(`make_report.py`, `report_lib.py`)·PPT(`make_ppt.py`)·도식(`diagrams_html.py`) 생성 스크립트

스크립트는 작성 환경의 경로(Windows 임시 폴더, `eval/private/submission/`)를 쓰므로 다른 환경에서 돌리려면 경로를 고쳐야 한다.
캡처에는 영상 화면의 자막이 일부 보이며, 보고서·PPT에 실린 범위로 한정한다. 원본 자막 전체와 gold 평가셋은 올리지 않는다.
